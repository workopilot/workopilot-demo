# Mate 普通用户端 Demo 设计

## 目标

在现有 Vben Admin 5.0 项目中新增一套面向普通用户的 Mate 前端 Demo。该用户端使用 `/app/mate` 路由空间，与现有管理后台的布局、菜单和视觉样式隔离。

实现以 `E:\work\git2026\agent_platform\wiseai.vue` 中 `/app/pharma` 用户端为主参考，迁移其页面结构、双层侧栏、绿色主题和关键交互；以 `E:\work\AI\aidemo\wkClient\matedemo` 补充演示文案、员工、文件和自动化任务数据。

项目仍是纯前端 Demo，不接入真实后端，不实现多语言。

## 实现策略

采用“精简迁移”方案：保留参考项目中用户可见的布局、页面和交互，将租户运行时、动态应用注册、后端 API、鉴权、多语言及业务平台依赖替换为本地类型、Mock 数据和轻量状态。

不复制参考项目的完整运行时框架，不修改 Vben 核心代码，也不把多个视图合并为单个巨型页面组件。

## 路由与入口

新增以下路由：

| 路径                             | 页面     | 说明                      |
| -------------------------------- | -------- | ------------------------- |
| `/app/mate`                      | 重定向   | 自动进入 `/app/mate/home` |
| `/app/mate/home`                 | 工作台   | 普通用户端首页            |
| `/app/mate/employees`            | 数字员工 | 员工卡片与列表视图        |
| `/app/mate/employee/:employeeId` | 员工对话 | 指定员工的对话工作区      |
| `/app/mate/files`                | 文件     | 文件资产、搜索和分类筛选  |
| `/app/mate/automation`           | 自动化   | 定时任务管理与执行日志    |

路由使用独立 `AppShellLayout`，不渲染现有管理后台的侧栏、顶栏、标签页和面包屑。管理后台新增一个“用户端 Demo”入口，跳转到 `/app/mate/home`。用户端账户菜单提供“返回管理后台”操作。

## 页面框架与视觉

### 独立 AppShell

页面采用参考 pharma 用户端的三栏结构：

1. 深绿色主导航栏：品牌标识、工作台、员工、文件、自动化和用户入口。
2. 浅绿色二级侧栏：随当前模块显示员工列表、文件筛选或自动化筛选。
3. 主内容区：显示当前路由对应页面。

二级侧栏支持折叠，折叠状态保存在 `localStorage`。桌面端完整展示，窄屏时缩小栏宽并隐藏非必要文字，保证主要操作仍可访问。

### 视觉令牌

沿用参考项目的绿色体系：

- 深色主导航：墨绿背景、白色激活项。
- 强调色：青绿色，用于按钮、选中态、状态和焦点。
- 二级侧栏：浅绿色背景与低对比边框。
- 内容区：浅灰绿色背景、白色内容面板。
- 圆角、阴影、卡片间距和悬浮反馈按 pharma 页面迁移。

样式限制在 Mate 用户端布局和页面作用域内，不覆盖管理后台的全局主题。优先使用 Tailwind CSS；参考页面中与布局强相关的复杂样式使用 scoped CSS 和 CSS 变量。

## 页面设计

### 工作台

工作台显示：

- 欢迎区和 Mate 应用简介。
- 数字员工、文件、自动化任务等概览指标。
- 最近沟通的数字员工，支持点击进入对话。
- 最近上传的文件，支持跳转文件页。
- 快捷入口，跳转员工、文件和自动化模块。

### 数字员工

员工页显示全部 Mock 员工，支持：

- 卡片和紧凑列表两种视图。
- 关键词搜索。
- 收藏与取消收藏，收藏状态保存在 `localStorage`。
- 在线状态和未读提示。
- 点击员工进入 `/app/mate/employee/:employeeId`。

员工对话页复用独立 AppShell，在二级栏保持员工列表；主区域包含员工信息、消息记录、快捷问题、输入框和模拟回复。发送消息仅修改前端内存状态，并使用短暂延迟模拟响应。

### 文件

文件页支持：

- 关键词、时间范围、文件分类筛选。
- 文件表格或列表展示。
- 文件类型、大小、上传人、更新时间和状态展示。
- 模拟上传：选择本地文件后生成一条内存记录，不上传到服务器。
- 模拟预览、下载和删除反馈。

筛选条件由二级侧栏维护，并通过查询参数同步到路由，刷新页面后仍能恢复当前筛选。

### 自动化

自动化页支持：

- 按关键词、状态和关联员工筛选。
- 任务卡片展示名称、描述、执行员工、Cron/周期、最近执行时间和状态。
- 新建与编辑任务抽屉。
- 启用、停用、删除和立即执行。
- 执行日志弹窗。

立即执行会写入一条新的 Mock 日志并更新最近执行时间，不触发真实调度。

## 数据与 API

`src/types/mate.ts` 定义员工、消息、文件、自动化任务、执行日志和筛选条件类型。

`src/api/mock-data-mate.ts` 统一保存初始 Mock 数据，素材可复用 matedemo 中的头像和业务图片。图片复制到当前应用的 `public/mate/` 目录，避免跨项目绝对路径引用。

`src/api/mate.ts` 提供 Promise 形式的前端 API：

- 查询员工、文件和自动化任务。
- 新增文件记录。
- 新建、更新、删除、启停和执行任务。
- 查询任务日志。
- 发送消息并返回模拟回复。

API 使用统一响应结构与短暂延迟。所有修改只在浏览器会话的内存中保留，刷新后恢复初始数据。

## 状态、错误和空态

- 页面首次加载显示 Spin 或骨架状态。
- Mock API 异常通过 `message.error` 提示，并保留页面当前数据。
- 搜索无结果显示对应空状态，不显示无休止加载。
- 删除任务使用 Popconfirm 二次确认。
- 表单提交期间禁用确认按钮，避免重复新增。
- 不支持的预览或下载动作给出明确的 Demo 提示。

## 组件与代码规范

- 使用 Vue 3 `<script setup lang="ts">` 和 Composition API。
- 所有 Ant Design Vue 组件显式导入并使用 PascalCase。
- 图标统一使用 `@iconify/vue` 的 Lucide 图标。
- 不修改 `packages/@core/`、`views/_core/` 等 Vben 核心文件。
- 不引入第二套组件库。
- 所有可见文案直接使用中文，不增加 i18n key。

## 验证与验收

实现完成后验证：

1. `/app/mate` 能正确重定向到工作台。
2. 五类页面均通过真实路由访问，浏览器前进和后退正常。
3. 用户端不出现管理后台菜单、顶栏和标签页。
4. 主导航、二级栏、折叠状态和绿色主题与 pharma 参考页面一致。
5. 员工搜索、收藏、视图切换和对话模拟可用。
6. 文件筛选、模拟上传和删除反馈可用。
7. 自动化筛选、增删改、启停、执行和日志查看可用。
8. 管理后台入口和用户端返回入口均可用。
9. 运行项目格式化、前端类型检查和 `pnpm build:antd`。
10. 启动本地页面，对桌面和窄屏布局进行视觉检查。

## 非目标

- 不接入真实后端、数据库、文件存储或任务调度。
- 不迁移 wiseai.vue 的租户、应用注册、鉴权和远程菜单机制。
- 不实现多语言。
- 不实现应用市场和其他行业应用。
- 不改变现有管理后台页面的信息架构和视觉主题。
