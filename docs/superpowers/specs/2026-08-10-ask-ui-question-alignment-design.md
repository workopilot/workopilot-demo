# Ask UI 题目编号与内容对齐设计

## 目标

强化连续题目的分组边界，并让题目标题、选项、补充输入和推荐说明形成统一的内容基线。

## 方案

- 每道题使用固定宽度的两列网格：左侧为题号轨道，右侧为内容轨道。
- `Q1`、`Q2`、`Q3` 使用紧凑绿色 Label；亮色主题采用浅绿底与深绿字，暗色主题提高背景和边框对比度。
- 问题标题、状态标签、选项卡片、文本输入、历史答案和推荐理由全部放入右侧内容轨道。
- 选项区域的左边缘与问题标题第一个字严格对齐；题目之间继续保留整行分割线。
- 移动端保留题号轨道，不将题号堆叠到标题上方，确保扫描顺序稳定。

## 实现范围

- 调整 Ask UI 前端模板的题目 DOM 分组。
- 调整 Ask UI 的题目、题号和响应式样式。
- 不改变问题 JSON 格式、答案保存协议和现有会话数据。

## 验证

- 检查选择题、文本题、历史轮次和“其他”补充输入的左边缘是否一致。
- 检查亮色与暗色主题下题号 Label 的可读性。
- 运行脚本语法检查、Ask UI 自测和技能快速校验。
