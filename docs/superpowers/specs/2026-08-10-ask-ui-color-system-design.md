# Ask UI 配色系统调整设计

## 目标

将 Ask UI 的主色统一为沉稳的森林墨绿，以鼠尾草绿承载浅色弱状态，并使用暖金色题号 Label 强化题目分组。

## 亮色主题

- 主色使用 `#0F5B3A`，用于主按钮、当前轮次、选中控件、推荐说明和主要强调信息。
- 悬停与按下色使用 `#044E32`。
- 选中卡片的浅色背景使用 `#E8F0EC`，边框使用森林墨绿的柔和混合色。
- 未选中态的辅助文字使用 `#4A6B5D`；正文和标题保持现有高对比中性色。
- 题号 Label 使用 `#FEF3C7` 背景、`#D97706` 文字和 `#B45309` 边框。

## 暗色主题

- 保持现有深色页面和卡片层级，不把浅色主题色直接作为大面积背景。
- 主强调色使用与森林墨绿同色相、适合深色背景的高亮绿色。
- 选中卡片继续使用低亮度深绿背景和高对比绿边框。
- 题号 Label 保持暖金色识别特征，背景使用降低亮度的深琥珀色，文字和边框使用更亮的暖金色。

## 实现范围

- 为题号增加独立的暖金色变量，避免复用全局绿色强调变量。
- 调整全局主色、悬停色、浅色强调背景、强调边框和弱文字变量。
- 不改变 DOM、布局、问题 JSON、答案提交协议或会话数据。

## 验证

- 检查 Q1/Q2/Q3 在亮暗主题下均清晰可读且与绿色操作色区分明确。
- 检查主按钮、轮次标签、选中卡片、单选框、复选框及推荐信息颜色一致。
- 检查未选中卡片仍具有足够对比度，题目标题不受弱文字色影响。
- 运行 Ask UI 自测、技能校验并检查浏览器控制台。
