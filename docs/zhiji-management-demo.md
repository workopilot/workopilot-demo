# 知记：AI 汇报管理 Demo

日期：2026-10-22。需求基线为统一汇报方案 V1.3，以及固定周期／汇报者自选周期的新增要求。

## 入口

应用 → 知记，默认进入 `/app/mate/apps/zhiji/schemes`。保留原 AI Work 入口供旧演示使用。

## 管理页面

- 汇报方案：搜索、类型／周期模式／状态筛选；新建、复制、保存草稿、发布、停用。
- 配置页：基本信息、周期与时间、数据与内容、AI 与模板、分发与反馈五个分节；按需配置预览、版本历史和离开提醒。
- 报告类型：个人、项目、产品线、客户四类内置对象；查看取数范围、默认结构及关联方案，编辑说明、启停类型。
- 数据源：展示系统来源、关联方案和模拟连接状态，测试连接和查看范围。Git 未授权不伪装连接成功。
- 内容与模板：成果汇报、项目进展、客户服务三种结构，预览及维护默认生成要求。修改模板不覆盖既有方案。

## 周期定义

报告类型定义业务对象；周期属于汇报方案。

- 固定周期：一个周期，汇报者只能选择具体哪一期。
- 汇报者自选：管理员设定允许周期和默认值，汇报者从中选择。
- 支持日、周、双周、月、季度、年度；自然周从周一开始，双周使用显式的周一起始日期，每 14 天连续划分。月、季度、年度使用自然边界。
- 覆盖周期、生成时间、应交截止分别配置。生成和截止按“周期结束后第 N 天 + 北京时间”表达。
- 自动生成仅为草稿；不自动提报、分发或创建任务。
- 自选周期的个人生成安排及应交记录调度规则在界面解释，当前没有真实调度与义务生成服务。

## 与汇报者端联动

- 发布后在新汇报助理的方案卡片中可见，草稿和停用方案隐藏。
- 周期选项与具体日期选择器随管理配置变化；切换周期保留原草稿并打开独立报告。
- 新生成的报告保存方案配置快照与周期；管理侧发布新版本不改变旧报告快照。
- 新个人报告的来源默认开关、默认分享与反馈人从配置快照读取；禁止调整分享对象时对应控件只读。
- 项目／客户已有工作台继续使用原场景结构。管理页可配置章节与模板并预览，尚未做完整的动态报告渲染引擎；不会宣称修改管理模板已重排既有业务工作台。
- 新建方案尚无业务样本时显示空草稿，不复制其他周期成果或编造样本数据。

## 推荐演示顺序

1. 打开项目进展汇报 → 周期与时间：勾选年报，修改默认值，预览自然年度边界。
2. 发布新版本，返回列表查看版本号；再次进入可查看旧配置快照。
3. 点击“打开汇报者端”，打开项目进展汇报，选择新增周期；无样本周期显示待采集状态。
4. 新建个人方案，设置固定季度，保存或发布；发布后在汇报助理入口可选。

## 实现边界

采用 Vue 3、TypeScript、Ant Design Vue、Lucide 图标及现有薄荷绿应用框架，使用 UI UX Pro Max 的企业操作界面指导。所有配置、版本、催办和重试状态均保存在前端内存，刷新后重置；不调用真实模型、业务系统、消息分发或定时服务。适用范围字段是演示配置，不代表真实权限校验。

测试覆盖跨年周、双周锚点及之前周期、闰月、自然季度／年度、草稿不可见、发布可见、报告配置快照隔离、空日期方案发布。

## 范围与数据源配置

适用范围通过部门或人员勾选，按部门时包含该部门全员；不设置生成负责人。列表展示所选范围，配置快照保存范围模式及选中 ID。当前为前端 Demo，真实目录和服务端访问控制仍需后续接入。

数据源通过可搜索、可滚动的弹窗批量选择，确认后进入已选列表，支持移除及逐项编辑总结提示词；搜索不影响其他已选项，取消不提交勾选变更。提示词随方案发布及报告配置快照保存，实际模型调用仍为模拟。

## 方案内模板配置

模板配置已移入每个汇报方案，独立模板管理入口移除。方案包含“AI 生成要求”和“模板配置”两个分节。模板以卡片展示，可设为可用或默认模板；末尾“添加模板”卡片打开侧滑栏，维护名称、大文本样式提示词及可选 HTML 参考文件。已有卡片可点击编辑。保存到方案后还需保存或发布整个方案；取消侧滑栏不会修改原模板。

每个方案保存独立模板及文件内容，汇报者端使用方案快照中的模板。HTML 文件当前作为样式参考保存，不直接运行，真实 AI 排版仍待接入。
