# 四步完成喔壳 Demo

## 1. 下载并运行

新建一个文件夹，用开发 Agent 打开，输入：

> 帮我克隆这个仓库到本地，运行起来，并打开左侧底部的帮助页面：https://github.com/workopilot/workopilot-demo

## 2. 选一个发布目录

首次运行时，Agent 会询问部署子目录。例如 `www.xxx.com/`**`wkdemo`**`/index.html` 中的 **wkdemo**。

换成自己的名称（如 `demo-zhang`），就能和同事的 Demo 区分，避免发布时互相覆盖。团队共用一个代码仓库时，可以约定共用一个目录；留空表示网站根目录。

## 3. 描述需求，生成 Demo

直接告诉 Agent 你想演示什么，例如：

> 帮我做一个周报 Demo：员工用汇报助理生成并提交周报，主管用审阅助理审批，管理员在应用里配置模板和审批规则。请用模拟数据完成整个流程。

Agent 会按项目规范开发，你可以边看效果边提出修改。

## 4. 发布并分享

本地确认效果后，告诉 Agent：

> 使用 wk-demo-publish 技能，发布到我配置的目录，验证后给我访问链接。

首次发布需提供服务地址、用户名和密码，按 Agent 提示在本地输入，保存到 `.env`，不提交 GitHub。**喔壳团队请向喔壳技术索要；其他团队请自行准备服务器和发布账号。**
