# 智能体员工模块功能说明

## 模块概述

本次更新新增了「智能体员工」（AI Employee）模块，主要用于管理、配置及使用智能体。该模块集成了工作台日常交互、主数据管理、智能体底层配置，以及相关的运营与计费功能，为用户提供了一站式的智能体管理与使用体验。

## 菜单及路由结构

该模块在一级菜单下新增了「智能体员工」，包含以下主要功能页面及子页面：

### 1. 智能体员工工作台 (`/ai-employee/workbench`)

- **功能说明：** 提供所有可用智能体员工的列表总览，用户可以在此页面选择并启动对应的智能体。
- **关联页面：** 包含点击进入后的「工作台会话」详情页 (`/ai-employee/workbench/chat/:id`)，支持用户与具体的智能体进行交互对话和任务协同。

### 2. 主数据管理中心 (`/ai-employee/data-center`)

- **功能说明：** 统一的主数据管理平台。支持对商品（如中成药、益生菌等）、业务规则及相关元数据进行集中维护更新。该中心的数据可以被各智能体调用，保证业务数据标准的统一。

### 3. 智能体配置中心 (`/ai-employee/agent-config`)

- **功能说明：** 查看当前系统中所有的智能体配置集合。适用于管理员或者运营人员管理并审查对应的智能体功能配置项。
- **关联页面：** 提供「编辑智能体」页面 (`/ai-employee/agent-config/edit/:id`)，支持对智能体进行更深度的提示词（Prompt）、调用参数设置及干预逻辑调整等二次开发配置。

### 4. 运营与计费管理 (`/ai-employee/billing`)

- **功能说明：** 主要用于管理该系统的 Token 开销、API 调用量、以及资源消耗分析等。提供基于智能体使用情况的计费详情和运营统计看板。

## 代码结构说明

新增页面及路由对应的源码路径为：

- 路由配置：`apps/web-antd/src/router/routes/modules/ai-employee.ts`
- 视图页面目录：`apps/web-antd/src/views/ai-employee/`
  - `/workbench/`：智能体工作台列表与会话页面
  - `/data-center/`：主数据管理中心
  - `/agent-config/`：配置与编辑页面
  - `/billing/`：运营与计费页面

以上模块均已按项目代码规范集成至最新代码库中。
